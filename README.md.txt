# NYC Taxi Trip Analytics (PySpark)

This project analyses NYC Yellow Taxi trips at scale using PySpark.
It focuses on trip efficiency metrics ($/min, $/km), temporal patterns,
geographic pickup zones, weather effects, and simple ML models.

**Tech:** PySpark, Python, SQL, Pandas, Matplotlib  
**Data:** NYC TLC Trips (2019), NOAA Central Park Weather

> Note: This repository reconstructs an original university assignment
> after submission. Raw datasets are excluded due to size and licensing.
